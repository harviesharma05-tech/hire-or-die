# 🧟 HIRE OR DIE V30
Learn Coding. Defeat Zombies. Get Hired.
A AAA-quality browser RPG - 30 levels, 6 maps, 10 bosses, 1000+ coding questions.
Built with HTML5 Canvas, Vanilla JS, Zero dependencies.

## Quick Start
1. Extract and open index.html
2. Or: python3 -m http.server 8000
3. Deploy to GitHub Pages

## Structure
- src/ - Game source code (40+ files)
- assets/ - Images, audio, data (300+ files)
- index.html - Entry point
- README.md - Documentation

## Features
✅ 30 Levels | ✅ 6 Maps | ✅ 10 Bosses | ✅ 1000+ Questions | ✅ RPG Systems | ✅ Mobile Support | ✅ Offline (PWA)
